سایت سینا حسن‌بیگی — نسخه اولیه

فایل‌ها:
index.html: متن و ساختار سایت
style.css: طراحی و نمایش واکنش‌گرا
script.js: منوی موبایل
sina-portrait.jpg: عکس برش‌خورده از رزومه پیوست

انتشار رایگان از گوشی با GitHub Pages:
1) در github.com حساب بسازید و وارد شوید.
2) repository جدید با نام دلخواه (مثلاً sina-consulting) و حالت Public بسازید.
3) فایل‌های این بسته را بارگذاری کنید.
4) Settings > Pages > Deploy from a branch را انتخاب کنید؛ Branch: main و Folder: /(root) و Save.
5) پس از چند دقیقه آدرس سایت در همان بخش Pages نمایش داده می‌شود، با فرم:
https://USERNAME.github.io/REPOSITORY/

دکمه رزرو به فرم شما وصل است: https://digiform.ir/w5253c4fb
دامنه اختصاصی اختیاری است و برای شروع لازم نیست.
